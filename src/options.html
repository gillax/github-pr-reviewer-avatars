GitHub PR Reviewer Avatars

This extension adds reviewer avatars to the GitHub pull request list (github.com/{owner}/{repo}/pulls). It needs a GitHub Personal Access Token (PAT) to read reviewer data — including from private repositories you have access to.

How your token is handled

  • Stored only in chrome.storage.local on this device — it is never synced to your Google account.
  • Used only by the extension's background service worker, which sends it only to https://api.github.com/graphql.
  • The page-side code never reads or receives the token, so it cannot appear in any website's network traffic.
  • This extension is open source — read the code to verify all of the above.

Creating a token

Either type of GitHub PAT works:

  • Classic token with the repo scope (covers public and private repos).
  • Fine-grained token scoped to the repositories you want, with Repository permissions → Pull requests: Read-only.
